2026-10-15 当前状态：文字发布、昵称邮箱留言和 R2 照片视频存储已连接。管理后台使用专用免密码入口，首次用私下保存的入口打开，之后原设备可直接进入后台。请自己保管入口，勿公开分享。后台照片按原图上传，不压缩、不生成缩略图，保留原文件及其拍摄信息；照片和视频每个最多 64 MiB，累计上传上限 10 GB。原片也继续保留在电脑上。视频支持 MP4/WebM，也可添加已有 HTTPS 视频直链。

电脑和手机都可以登录后台写旅行日记、生活碎片、建相册，选择照片时会直接上传原文件。可以预览、保存草稿、发布、设置精选、管理友链，以及回复或隐藏昵称邮箱留言。照片和视频保存在 R2，GitHub 保存文字和媒体链接。

下面也保留电脑上编辑文件的方式；用编辑器修改后，提交并推送到 GitHub。

## 写旅行日记、生活碎片或日常

后台「类型」可选择「生活碎片」「旅行日记」「日常」和「无」。「无」表示不设置分类；日常和无分类记录仍会显示在首页，并可通过分类或归档查找。旅行日记、生活碎片继续分别进入对应栏目。

后台正文采用图文编辑：先写一段文字，把光标放到要插图的位置，点击「＋ 在光标处插入照片」。上传后会在该位置显示原图，图片下方可以接着写下一段；可以修改照片说明、上移、下移或移除图片。下方附件列表中的已有照片也可以点击「插入正文」。点「预览」查看文字与图片的完整顺序，确认后保存草稿或发布。已插入正文的照片不会再在文章末尾重复显示。相册仍按独立图库编辑，视频仍在正文后显示。

2026-10-17：普通中文段首的多余空格会自动整理为正常段落，避免被误识别成黑底代码块；明确使用代码围栏的示例和列表格式保持不变。文章图片居中、比文字略窄，点图仍可放大查看原图。页面显示使用独立的公开媒体地址，原图文件与文章中保存的原始地址不变。

2026-10-18：正文按一次回车就会换行，空一行仍表示分段，后台预览、发布页和 RSS 保持一致。文章标题下显示浏览量，从本次上线开始累计，历史访问无法补回；同一浏览器当天重复访问同一篇文章只计一次，以北京时间划分日期。更换设备或清除浏览器数据后可能重新计数，因此它是去重浏览量，不是精确人数。访客评论和后台回复框都可以点选常用表情；点击某条评论的「回复」后，会显示正在回复的昵称，也可以取消。已存在的回复自动显示在原留言下面，并注明回复对象。隐藏原留言不会删除其他人的回复，页面会提示原留言已隐藏或暂不可见。

1. 复制 docs/templates/travel.md 或 docs/templates/moment.md 到 src/content/posts/，起一个不重复的文件名，例如 hangzhou-autumn.md。
2. 修改顶部的标题、日期和分类，正文写在第二条分隔线后面。
3. 预览确认后，把 draft: true 改成 draft: false，再提交发布。

也可以运行下面的命令创建新文章。新文章默认是草稿。

~~~powershell
pnpm new-post my-first-note
~~~

“旅行日记”和“生活碎片”分别对应两个栏目；分类文字要一致。格式示例：

~~~md
---
title: 杭州的秋天
published: 2026-10-13
description: 这次旅行中想记住的几个瞬间。
image: ''
tags: [杭州, 秋天]
category: 旅行日记
draft: true
featured: false
lang: zh_CN
---

在这里写自己的经历。

![湖边的树](/media/hangzhou-2026/001.webp)
~~~

草稿不会显示在网站文章列表、搜索和订阅中。**公开 GitHub 仓库里的源文件仍然可以被别人查看**，所以私人日记和原片请留在本地；草稿开关不是访问密码。

将 featured 改为 true 后，这篇记录会出现在「精选记录」。友链可以在后台管理，或编辑 src/data/friends.json。每个朋友可以填写「网站简介」和「我的备注」：简介介绍对方的网站，备注写你自己的关系或印象；备注会公开显示在友链页和侧栏，留空就不显示。

在文章顶部还可以增加 photos 照片组和 videos 视频列表，网页会显示分组缩略图、点击放大和视频播放器：

~~~yaml
photos:
  - src: https://自己的媒体地址/001.webp
    thumbnail: https://自己的媒体地址/001-thumb.webp
    alt: 湖边的树
    width: 1920
    height: 1280
videos:
  - src: https://自己的媒体地址/travel.mp4
    caption: 路上的一小段
~~~

在发布后台选择照片，会自动生成原图地址和尺寸，不必手写；thumbnail 仅用于已有的可选缩略图，后台不会生成缩略图。

## 本机自动暂存与恢复

2026-10-19：在后台编辑日记或相册时，停止输入约半秒后自动暂存，显示「本机已暂存」。上传成功的照片链接、照片说明、封面和旅行系列设置也会一起保存。切换到其他记录或应用时会再尝试暂存；关闭或刷新页面时，浏览器可能显示未提交提醒。

重新打开后台，展开顶部的「本机未提交的记录」，点击「恢复」继续编辑；也可以导出或删除单份暂存。只有点击「保存草稿」或「发布记录」才会提交到网站，提交成功后会清理当前编辑对应的暂存。其他记录、其他标签页的独立暂存不会被一起清空。

本机暂存只保存文字、设置和图片链接，不复制原图，不占用 R2 或 D1 空间。程序为暂存数据设置约 100 万个 UTF-16 字符的总上限（文本数据约 2 MB，不包含浏览器自身开销），不会为了腾空间静默删除旧记录。空间不足或浏览器拒绝存储时会显示失败提示，可先点「导出当前内容到本机」，或手动保存到网站。

**暂存仅存在当前设备的当前浏览器中，不会同步到其他设备，也不是长期备份。清除浏览器数据、卸载浏览器或设备故障可能使其丢失。** 导出的 JSON 保存文字、字段和图片链接，可作为恢复参考，不包含原图文件或登录凭据，目前不提供文件导入按钮。退出管理不会删除暂存；共享设备上请自行导出并清理。

如果手机和平板编辑了同一篇文章，旧版本不能覆盖线上新版本。后台会保留本机文字，并显示可供比较的线上最新内容；可以导出备份，或点击「将本机内容另存为新记录」。若要继续编辑原文章，可先保留本机暂存，再重新打开线上记录并手动合并需要的段落。

## 旅行系列

在日记和相册的「旅行系列（可选）」中填写同一个系列名称，例如「2026 国庆之旅」。还可以填写旅行日期、地点和系列顺序；留空系列名称则不归入任何系列。系列名需要完全一致，首尾空格会自动去除。

- 发布后，进入「旅行日记」→「全部旅行系列」，即可按旅程查看日记与相册。
- 系列目录显示日期、地点及关联记录；文章末尾会显示同系列上一篇、下一篇和完整目录，相册也能返回同一旅程。
- 填写了系列顺序的记录优先按数字升序排列；其余按旅行日期从早到晚排列。旅行日期未填时使用文章或相册的记录日期。
- 草稿不会进入公开系列。旧文章不会自动分组，需要在后台填写系列名称并重新发布。
- 系列只关联已有记录，不复制照片或创建额外的媒体文件，不需要新建数据库表。

## 可选：导入压缩照片和相册

原片放在网站项目外的本地文件夹，并另做备份。导入工具只读原片，生成网页用的压缩照片和缩略图；不会覆盖、移动或删除原片。

~~~powershell
pnpm import-photos "D:\照片\杭州旅行" hangzhou-2026 --title "杭州的秋天" --date 2026-10-13 --description "在湖边走走停停。"
~~~

也可以把第一个参数替换成单张照片的完整路径。相册标识 hangzhou-2026 用小写英文、数字和短横线，不能与已有相册重复。文件夹只读取第一层照片，不递归导入子文件夹；每次最多 500 张。支持 JPEG、PNG、WebP、AVIF、TIFF，手机 HEIC 请先导出 JPEG。

工具会自动调整照片方向，并生成：

- 最长边不超过 1920 像素、质量 80 的 WebP 照片。
- 最长边不超过 640 像素的缩略图，小图片不会被放大。
- public/media/hangzhou-2026/ 下的压缩文件。
- src/data/albums/hangzhou-2026.json 相册资料，供相册页显示。

网页文件会去掉 EXIF、GPS 等元数据；相册资料中不记录原片路径。压缩文件按原文件名排序后使用 001.webp、002.webp 等编号，不保留原文件名。

导入后可以在相册 JSON 里修改 title、date、description，并为每张照片的 alt 填写简短的画面描述。照片的 width、height 是压缩文件的真实尺寸；请保持一致。已有相册不会被脚本覆盖；想追加照片，可以先建一个新相册标识，或手动整理相册 JSON。

相册导入即成为待发布内容，提交前先检查选片。暂时不显示某个相册，可以在它的 JSON 顶层增加 "draft": true。需要在日记里放同一张照片时，直接引用 /media/相册标识/001.webp，无需复制一份。

## 长期使用：照片和视频可以移到外部存储

电脑导入工具生成的压缩版仍然会占用 GitHub 仓库和发布空间。日常发布推荐在后台直接上传原图和视频，文件会存入 R2，GitHub 只保存链接。相册和文章也支持其他公开可访问的 HTTPS 图片地址。请使用能直接返回图片的地址，普通网盘分享页通常不能直接显示。

相册 JSON 中，一张照片可以写成：

~~~json
{
  "src": "https://你的图片域名/travel/001.webp",
  "thumbnail": "https://你的图片域名/travel/001-thumb.webp",
  "alt": "湖边的树",
  "width": 1920,
  "height": 1280
}
~~~

上面的域名只是格式示例，需要换成自己实际使用的地址。换存储时只需修改这些地址，博客页面可以继续使用。原件和备份继续由本地保存，云端文件不替代本地备份。

## 发布视频

在文章正文里粘贴下面的代码，并把 src 换成可公开播放的视频文件地址：

~~~html
<video controls playsinline preload="metadata" style="width: 100%; border-radius: 12px;" src="https://你的视频域名/travel.mp4"></video>
~~~

建议使用浏览器兼容的 MP4（H.264 视频、AAC 音频）。controls 显示播放按钮，playsinline 方便手机内嵌播放，preload="metadata" 避免打开文章就预加载整段视频。视频的服务器需要允许公开访问，使用 HTTPS，并支持浏览器播放所需的文件类型和分段读取。

照片导入工具不处理视频。Cloudflare 连接完成后，可以在后台选择 MP4/WebM 短视频上传，每个最多 64 MiB，工具不自动转码。较大的视频可以先压缩，或使用可播放的外部视频直链；视频平台的视频也可以按平台提供的嵌入代码放进文章。

## 电脑上预览和发布

首次打开项目需要 Node.js 24 和 pnpm 9。安装依赖后启动本地预览：

~~~powershell
pnpm install
pnpm dev
~~~

打开终端显示的本地地址即可查看。正式发布前运行：

~~~powershell
pnpm check
pnpm build
~~~

通过后，把修改提交并推送到仓库的 main 分支。GitHub 的 Actions 页面可以查看发布是否完成；推送后需要等待构建，刷新网站才会看到更新。

修改网站名称、介绍、头像等，编辑 src/config.ts。关于页正文在 src/content/spec/about.md，由 src/pages/about.astro 渲染。记录管理使用站主专用入口，博客阅读仍是公开的，未提供仅好友可见的记录。
